    本輪方法論重點

    • 先把 SQL 學成骨架，不追花式語法。
    • 每週至少留下 1 份案例與 1 條方法。
    • 用「資料、流程、角色、狀態、規則」五軸看需求。
    • 讓「案例 → 歸納 → 方法」的循環穩定發生。

    回報前檢核

    • 能不能不用看答案重寫。
    • 能不能白話解釋。
    • 能不能對應到工作情境。
    • 有沒有留下筆記、題目或 review。
    • 有沒有記下卡點與修正方向。
