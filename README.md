# Career Goals - SA Learning Hub

這是一個以 **SQL → 資料模型 → 系統規格 → 測試思維** 為主幹的個人學習與成果沉澱專案。

## 專案目的
- 用 GitHub Repository 保存成果、筆記、SQL 練習、方法論與案例
- 用 GitHub Pages 提供可視化首頁、每週進度頁與心智圖入口
- 用方法論庫與案例庫逐步沉澱個人 know-how
- 為未來串接 GitHub Projects、Notion、Asana、資料庫、JSON 資料源預留空間

## 專案結構
- `docs/`：GitHub Pages 發布用前端
- `methods/`：方法論庫
- `cases/`：案例庫
- `specs/`：之後擴充的規格庫
- `roadmap.md`：主線與里程碑
- `architecture.md`：整體架構示意與資料流
- `mindmap.md`：Mermaid 心智圖主線

## 建議的使用節奏
1. 每週更新 `cases/weekXX/`
2. 從案例萃取出方法，更新 `methods/`
3. 同步更新 `docs/assets/data/weekly-progress.json`
4. 重新整理 GitHub Pages 網站，檢視首頁與進度頁

## GitHub Pages 設定
建議使用：
- Branch: `main`
- Folder: `/docs`

設定後，`docs/index.html` 會成為網站首頁。

## 第一批要先養大的內容
- 方法論庫
- 案例庫

先讓「案例 → 歸納 → 方法」這個循環跑起來，再擴張規格庫、趨勢庫與個人洞察庫。
